# Cybersecurity Governance & Security Policy Projects

A portfolio of academic cybersecurity governance case studies completed as part of coursework in information security policy at the University of South Florida.

These projects use **fictional organizations** and describe **proposed controls and policies**. They do not represent production implementations, compliance certifications, or security audits.

## Projects

| Project | Focus |
| --- | --- |
| [Remote Access & Home Network Security Policy](policies/remote-access-policy.md) | VPN, MFA, endpoint controls, access approval, remote user training |
| [Security Awareness & Training Policy](policies/security-awareness-policy.md) | SETA, phishing awareness, training governance, vendor RFI |
| [Separation of Duties & Access Governance Policy](policies/separation-of-duties-policy.md) | Least privilege, independent approvals, fraud prevention |
| [Security Policy Framework Implementation Plan](frameworks/security-policy-implementation-plan.md) | Policy rollout, communications, training, review, and feedback |
